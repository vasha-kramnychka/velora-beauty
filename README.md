# VELORA BEAUTY

Готова стартова версія інтернет-магазину косметики.

## Файли
- `index.html` — структура сайту
- `style.css` — дизайн і адаптивність
- `script.js` — каталог, пошук, фільтри, кошик і форма замовлення

## Як запустити на GitHub Pages
1. Завантажте ці файли в корінь репозиторію `velora-beauty`.
2. В GitHub відкрийте `Settings` → `Pages`.
3. У `Build and deployment` виберіть:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Натисніть `Save`.

Після публікації GitHub покаже адресу сайту.

> Товари зараз демонстраційні. Їх можна замінити у масиві `products` у файлі `script.js`.
